# Новая главная ancomp.ru: анализ, прототип, варианты дизайна

## Общее для всех вариантов

- Фирменные цвета с текущего сайта и логотипа: графит `#17181E`, коралл `#F15B47`, серый `#5D6771`. Кнопки — `#D23E2A` (тот же коралл темнее, ради читаемости белого текста).
- Шрифт Montserrat, как на текущем сайте.
- «Личный кабинет» и «Корзина» со счётчиком в шапке на всех экранах, включая телефон. Корзина — отдельная страница.
- Популярные категории каталога, отраслевые решения, проекты с фото, блок для партнёров и дилеров, простая форма заявки.
- Макеты свёрстаны как обычные HTML-страницы и работают на телефоне. Формы ничего не отправляют.

## Оговорки

- Фото оборудования и проектов взяты с ancomp.ru и принадлежат ООО «Анкомп». Для настоящего сайта нужна съёмка объектов: многие текущие фото любительские или сгенерированные. Для LED-экранов на сайте нет предметного фото на белом фоне, в макетах стоит кадр с выставки.
- Логотипы и фото заказчиков (Газпром, Полюс, O'STIN и др.) — только с их согласия.
- Выгоды для партнёров в макетах — черновик, их нужно сверить с Анкомпом.
- Названия заказчиков в блоке «Нам доверяют» взяты из проектов на сайте. Показ логотипов нужно согласовать с заказчиками.
